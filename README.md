# LylesC_SDC486L_Credit_Card_Fraud_Detection_Final_Project
Final project for SDC486L AI/ML and Advanced Data Analytics Lab demonstrating credit card fraud detection using machine learning, neural networks, Power BI, and scenario analysis.

Credit Card Fraud Detection Using Machine Learning and Neural Networks
Christopher J. Lyles

Course: SDC486L AI/ML and Advanced Data Analytics Lab

Instructor: Haylee Liska

Project Overview

This project demonstrates the application of data analytics, machine learning, neural networks, and business intelligence to detect fraudulent credit card transactions.

The project follows the complete analytics lifecycle, including:

Data preparation
Exploratory Data Analysis (EDA)
Machine learning model development
Neural network implementation
Scenario analysis
Interactive Power BI dashboard
Business recommendations
Dataset

Credit Card Fraud Detection Dataset

284,807 transactions
492 fraudulent transactions
Highly imbalanced dataset used for binary classification

Machine Learning Models

The project compares multiple predictive models, including:

Logistic Regression
Decision Tree
Neural Network (nn_model)

Model performance was evaluated using classification reports, confusion matrices, and scenario analysis.

Scenario Analysis

The completed notebook includes scenario testing using the trained neural network:

Baseline Transaction
High-Risk Transaction
Typical Customer Transaction
Suspicious Behavioral Pattern

These scenarios demonstrate how prediction probabilities change under different transaction conditions.
